# 《發燒的第七天》適性學習版

原版遊戲（repo 根目錄的 index.html、data.js、net.js、config.js）**完全沒有修改**。
適性學習版放在 `adaptive/` 資料夾，網址是原網址後面加 `/adaptive/`，
例如 `https://lgshlgsh-lab.github.io/pneumonia/adaptive/`。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 主持端＋學員端（同一頁，和原版一樣） |
| `data.js` | 劇情流程、15 題核心題、3 題救援題、54 題關聯題、結局文字卡 |
| `net.js` | 連線層，資料寫在 Firebase 的 `rooms_adaptive/`，不會和原版的 `rooms/` 混在一起 |
| `config.js` | 設定檔（Firebase、主持人密碼、背景音樂、補強門檻） |

沿用上一層的檔案：原版 87 張圖 `../img/`、背景音樂 `../BGM_*.mp3`、`../qrcode.js`，
前後測題庫與滿意度調查直接讀 `../data.js`，所以新舊兩版的前後測一模一樣、可以合併分析。

## 上線前要做的一件事：Firebase 規則

到 Firebase 主控台 → Realtime Database → 規則，把原本 `rooms` 那一段複製一份，改名成 `rooms_adaptive`。
例如原本是：

```json
{ "rules": { "rooms": { ".read": true, ".write": true } } }
```

改成：

```json
{ "rules": {
    "rooms": { ".read": true, ".write": true },
    "rooms_adaptive": { ".read": true, ".write": true }
} }
```

（請以你現在實際的規則為準，只是多加一段同樣的 `rooms_adaptive`。）

## 主持人操作（和原版一樣的地方）

- 方向鍵左右翻頁、空白鍵＝開始作答／公布／下一張、F 全螢幕、G 跳頁、M 音樂
- 前測、後測、滿意度調查、匯出 CSV 都在下方控制列

## 新增的操作

1. **分支題與救援題**（1-1、4-1、5-2、R1–R3）：按「公布分布」只顯示全班分布，不公布對錯。
   這時控制列會出現「劇情走向」，預設是最多人選的選項（平手走後果較差的），需要時可手動改。
   按「下一張」播後果場景 → 結算（公布對錯與排行）。
2. **進階思考題**：答錯率超過門檻，結算畫面會提示，按「下一張」進入進階思考題：過場 → 關聯題 3 題。
   3 題平均答錯率仍過半，會出現「講師補充卡」。上方「進階題」選單可切換 >50% ／ ≥50% ／ 關閉。
3. **狀態列**：上方「繞路｜過度｜ICU」顯示全班劇情狀態；播到投影片 83 之後自動進入對應結局，
   接著是「你們走過的路」回顧頁，再到 Debriefing。
4. **跳頁**可以輸入原版張數（例如 47）或代號（例如 a-q10）。注意：跳頁和上一張不會回復劇情狀態。

## 投影片圖片

- 原版圖片的選擇卡與結算卡上印著舊的選項，新版會用文字面板蓋住那半邊；之後重新生圖可以換掉。
- 新增投影片（支線場景、結局 B／C／D、救援題等）目前以文字卡呈現。
  生好的圖放到 `adaptive/img/<代號>.webp` 就會自動改用圖片，例如 `adaptive/img/al1.webp`、`adaptive/img/EB1.webp`。

## 示範模式

把 `config.js` 的 `firebase: {...}` 內容清空，就會進入示範模式：同一台電腦、同一個瀏覽器開多個分頁即可測試。
